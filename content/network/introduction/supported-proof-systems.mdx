# Supported Proof Systems

Fermah is designed to accommodate any proving system. These are the ones we currently support:

- [Jolt by a16z](https://jolt.a16zcrypto.com/) — A RISC-V based zkVM that uses a lookup-centric approach to prioritize simplicity and speed.
- [Groth16 by Jens Groth](https://www.zeroknowledgeblog.com/index.php/groth16) — A classic zk-SNARK offering very small proof sizes and fast verification, requiring a per-circuit trusted setup.
- [The RISC Zero zkVM](https://dev.risczero.com/api/) — A general-purpose zkVM that proves the execution of ordinary Rust/RISC-V programs.
- [Valida by Lita](https://lita.gitbook.io/lita-documentation) — A zkVM and instruction set architecture designed for efficient STARK proofs.
- [Stwo by Starkware](https://github.com/starkware-libs/stwo) — StarkWare's high-performance next-generation prover built on Circle STARKs.
- [SP1 by Succinct Labs](https://docs.succinct.xyz/) — A performance-focused, open-source RISC-V zkVM that proves arbitrary Rust programs.

Very soon, we will also support:

- [The Nexus 2.0 zkVM](https://docs.nexus.xyz/)
- [Stone by Starkware](https://github.com/starkware-libs/stone-prover)
- [The Aztec Proof System](https://docs.aztec.network/)

This initial support allows developers to integrate these systems quickly and leverage Fermah's capabilities without additional setup.

We plan to support all major proving systems.
