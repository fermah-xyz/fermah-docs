# Adding a New Machine

To add a new machine to your <GlossaryTooltip>Prover Node</GlossaryTooltip> setup, generate a new machine secret on the new machine:

```bash
prover-node gen-machine-secret
```

This generates a new Machine Secret Key and updates the configuration file accordingly. You can then proceed directly to [Registration](/network/mainnet/registration) and [Starting a Node](/network/mainnet/starting-a-node).

<Callout type="info">
Make sure you have already imported your ECDSA private key on the new machine before running this command. See [Machine Secret](/network/mainnet/machine-secret) for details.
</Callout>
